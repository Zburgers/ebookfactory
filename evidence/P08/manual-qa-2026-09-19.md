## Defects found and repaired

1. The existing EPUB navigation listed only the book title even though the
   manuscript contained four section headings. `_make_epub` now gives headings
   stable anchors and emits each heading in the EPUB navigation. Validation now
   checks the heading-link count, and a regression test covers the real EPUB
   bytes. A fresh synthetic package passed EPUBCheck with clickable
   `section-1` and `section-2` links.
2. Generated PDFs exposed anonymous document properties even though
   `metadata.json` named the title and author. The exporter now writes title,
   author and subject metadata, and validation checks for PDF title/author
   fields.
3. The prior local cover gate was documented as a KDP 5 MiB limit. Current KDP
   guidance says the cover file must be under 50 MB; the exporter and docs now
   use the 50 MB ceiling and generated covers carry 300 DPI metadata. The
   existing generated cover was already well below either threshold.
